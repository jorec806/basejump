# basejump

Conversor y evaluador de expresiones numéricas en bases de 2 a 36, escrito en C.

> Estado: en revisión. El proyecto depende de una biblioteca académica que ya no está disponible y actualmente no compila.

## Objetivo

- Convertir números entre bases.
- Convertir y evaluar expresiones aritméticas.
- Ofrecer modos interactivo y por archivo.

## Trabajo pendiente

- Implementar localmente el control de terminal.
